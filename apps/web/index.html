COMMITQUEST // BUILD 0.1

Level up from real commits.

Sign in with GitHub so CommitQuest can use your identity and public commit activity for XP and quests. Shared 2D overworld — WASD to move, Space or click to attack. No classes; ten stats start at 0.

Sign in with GitHub

Create a GitHub OAuth App (Homepage http://localhost:5173, Callback http://localhost:3001/api/auth/github/callback) and set GITHUB_CLIENT_ID / GITHUB_CLIENT_SECRET with AUTH_MOCK=false. See the README.
